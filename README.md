# 我的电子衣橱

中文个人电子衣橱 Demo。最新完整版本是 **单文件 HTML**，CSS、JavaScript 和示例图片均内嵌，无需后端、账号或模型服务。

## 直接运行

用现代浏览器打开 [`deliverables/我的电子衣橱.html`](deliverables/我的电子衣橱.html)。无需安装依赖，也不需要联网。

数据保存在当前浏览器的 localStorage 中。文件模式和 localhost 模式的存储相互独立，切换浏览器或地址不会自动迁移数据。请允许浏览器使用本地存储。

## 功能

- 首页：统计、今日穿搭记录、最近衣物、搭配和灵感。
- 衣橱 V0.2：轻量概览、五个智能集合、组合筛选、跨属性搜索、快速添加与批量添加、衣物状态、使用统计、详情与关联搭配。原有上传、拖放、编辑、删除和收藏保留。
- 搭配：创建、再次查看与编辑，画布添加单品、拖动、四角缩放、图层调整、移除及保存。
- 灵感：图片收藏、来源链接、备注、详情、删除、模拟识别、相似衣物，以及自动带入搭配编辑器。
- 我的：身高、体重、肩宽、胸围、腰围、臀围与内侧腿长；周/月/年度穿搭日志与爱用单品。
- 全中文界面、底部导航、删除确认、保存反馈与空状态。

穿搭记录支持选择已保存搭配或直接勾选单品、日期、场合、备注及可选实穿照片。爱用单品按周期内穿着记录次数排序，同一条记录中同一件单品只计一次。周从周一开始，月和年采用自然月与自然年。历史记录保留单品快照，衣物或搭配后续变化不会改写历史。

图片识别目前根据文件名生成**模拟结果**，不是实际 AI 识图。身材数据、图片和穿搭记录均保存在本地，不会上传到服务器。首次打开自动初始化 12 件衣物、4 套搭配和 8 张灵感插画；穿搭日志初始为空。

## 源码与生成

```bash
npm ci
npm run build:standalone
npm test
npm run lint
npm run build
```

`build:standalone` 将源码与本地 SVG / WebP 图片打包为两个相同的独立文件：

- `deliverables/我的电子衣橱.html`：可直接交付的文件。
- `public/wardrobe.html`：开发服务器中的预览入口。

请编辑 `standalone/` 中的源码，再运行生成脚本，避免直接修改生成文件。

```bash
npm run dev
```

最新完整版本访问 `http://localhost:3000/wardrobe.html`。Next.js 版本的 `/`、`/wardrobe`、`/outfits` 和 `/inspiration` 保留上一阶段的核心流程；今日记录、“我的”、拍照分流与衣橱 V0.2 在单文件版本中。

## Netlify 部署

仓库根目录的 `netlify.toml` 会运行 `npm run build:standalone`，跳过自动识别的 Next.js Runtime，并发布 `netlify-dist/`。构建脚本同时生成 `netlify-dist/index.html` 与 `netlify-dist/wardrobe.html`，因此 Netlify 根网址和原有 `/wardrobe.html` 地址都会直接打开同一个最新版。不要在 Netlify 控制台把发布目录改回 Next.js 的构建输出。

## 视觉规范

单文件版通过 `standalone/minimal.css` 应用统一的时尚编辑视觉：暖白背景、低饱和绿色操作色、宽松留白、4:5 单品图片、视觉化智能集合、杂志式首页、情绪板搭配画布与瀑布流灵感页。桌面端和 1024px 宽度均保持完整布局，手机端采用双列图片浏览与底部导航。样式独立实现，不加载外部字体；原有业务交互与存储键保持不变。

衣物示例采用 AI 生成的实物摄影风格透明底素材（`public/images/clothing-*.webp`），并内嵌到单文件 HTML。旧的内置插画会在加载时自动替换，用户上传照片保持原样；历史日志中的示例单品快照也会同步显示新素材。

## 衣橱 V0.2

- 智能集合：最近 30 天添加、按穿着次数排序、超过 60 天未穿或从未穿、收藏、工作场合。
- 筛选：类别、颜色、季节、场合、状态、使用频率。同一组多选为“或”，不同组与分类标签、搜索、智能集合之间为“且”。“清除全部”清空抽屉中的筛选。
- 使用频率：0 次为从未穿过，1–4 次为很少穿，5 次及以上为经常穿。
- 搜索：名称、类别、颜色、品牌、场合、季节；支持中文及常用英文分类词，例如 `work`、`black`。
- 快速添加只需照片、类别与颜色，名称可留空自动生成；品牌、季节、场合、材质、尺码、备注在“添加更多信息”中。
- 批量添加：选择多张图片 → 模拟分类 → 逐件调整类别、颜色 → 一次保存。识别只基于文件名，未连接 AI 服务。
- 状态内部使用 `Available / Laundry / Storage / Borrowed`，界面分别显示“可穿 / 待洗 / 收纳中 / 外借”。
- 穿搭记录的新增、日期编辑、单品调整及删除都会同步回算使用次数与最近穿着日期，同一记录内的同一单品仅计一次。内置示例包含初始使用历史。
- 衣物详情显示相关搭配；“用这件单品创建搭配”会将单品预先放入画布。
- 旧数据自动补齐字段，保留上传照片、名称、收藏、搭配及日志。所有更改继续保存在原 localStorage 键中。

验证：`npm test` 覆盖集合、组合筛选、中英文搜索、旧数据迁移与重载、穿搭统计回算、快速添加、批量复核保存、取消处理，以及原有衣橱/相机/剧情流程。`npx tsc --noEmit` 与 `npm run lint` 验证类型和源码。
